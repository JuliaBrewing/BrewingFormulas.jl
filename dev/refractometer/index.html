Refractometer

Refractometers are calibrated for sucrose solutions; wort reads higher by the wort correction factor, and once fermentation starts the alcohol distorts the reading, so the final gravity is estimated by an empirical fit.

BrewingFormulas.refractometer_gravity — Function
refractometer_gravity(reading; wcf = 1.04)

The gravity, in °P, of an unfermented wort from the refractometer reading (in Brix), corrected by the wort correction factor wcf. The default 1.04 is the value commonly used (and the factor for wort in the Python BrewQuiver); it is best determined for each refractometer against a hydrometer.

source
BrewingFormulas.refractometer_final_gravity — Function
refractometer_final_gravity([model = TerrillCubic()], initial, final; wcf = 1.04)

The apparent final gravity, in sg, estimated from the refractometer readings (in Brix) of the wort before fermentation, initial, and of the fermented beer, final, both corrected by the wort correction factor wcf, with Sean Terrill's fits (TerrillCubic or TerrillLinear).

References

  • S. Terrill, "Refractometer FG Results", 7 April 2011, http://seanterrill.com/2011/04/07/refractometer-fg-results/ (cited by the Python BrewQuiver).
julia> refractometer_final_gravity(12u"Brix", 6.5u"Brix")
1.0129859456476515 sg
